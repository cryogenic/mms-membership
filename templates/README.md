# templates/

Template paparan untuk modul keahlian MMS.

- `registration/` — borang pendaftaran multi-step (Fasa 2)
- `admin/` — skrin semakan permohonan (Fasa 3)
- `portal/` — portal ahli (Fasa 4)
- `emails/` — templat emel (Fasa 4–5)

Direktori ini masih kosong kerana Fasa 1 hanya menyediakan struktur plugin.
